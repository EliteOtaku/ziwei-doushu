## 二、核心待决问题：大限四化该不该用

### 2.1 争议来源

仓库里有一句措辞很硬的注释（`lib/ziwei/patterns.ts` 第 6 行，位于「设计原则」标题下）：

```
2. 倪师立场：不使用宫干自化、大限四化、来因宫等飞星派工具
```

但同一个仓库的其余部分都在**支持并使用**大限四化：

- `lib/ziwei/sihua.ts` 明确实现「运限四化 = 大限宫干 / 流年干 / 流月干…」
- `lib/ai/chart-context.ts` 会把当前大限四化写进喂给模型的文本
- 上游 README 把「生年四化、大限 / 流年四化、飞星自化」列为引擎特性

于是提示词层面出现分歧：上一版我的提示词写「大限四化看这十年」，你的 D1 进一步写成「**仅使用**生年四化与当前大限四化」。

**关键疑问**：如果 `patterns.ts` 说的是真的（倪师不用大限四化），那 D1 就是把一个体系外工具抬成了核心；如果那句注释只是"格局识别模块不借助飞星工具"的局部约束，那 D1 没问题。这个我判断不了，需要你的领域知识。

**我的初步读法**：这 23 条里的「大限」多数指「十年这个时间段」或「寿限/死期」，论运势时看的是**大限宫位的星曜**（如"陀罗星进来就是大限了"），而不是"用大限宫干起四化"。而「四化」5 条全部指科权禄忌（即生年四化），没有一条讲大限四化。

**但我必须诚实标注这个证据的边界**：
- 语料是从 14 讲《天纪》里节选的 1849 条，**不是全集**
- 「0 次」只能说明"这批精选原话里没讨论"，**不能证明倪师从未使用**
- 语料是口语转写，术语可能被讲成别的话（如不说"宫干四化"而直接说某宫化忌）
